## 为什么都不行 —— 两个叠加的原因

**一、`‖Δz‖` 这个度量在本架构上天然饱和。**
`z = LayerNorm(proj(pooled))`,LayerNorm 把 z 的范数固定在 √256,所以 `‖Δz‖` 实际量的是**角度变化**。
实测:遮住红球 0.9246,遮住**等面积空地板** 0.9203,**差 0.2%**。换模糊填充仍是 0.9174 vs 0.9140。
不是填充方式的问题,是度量本身没有分辨力。

**二、冻结表征 + 线性探针对任何局部扰动都极不鲁棒。**
把目标换成"遮住后红球方位预测偏了多少度",结果遮住**空地板**就已经偏 **25.5°**(量程 ±35°)。
探针是在干净图上拟合的,任何 20×20 的局部扰动都让特征跑出分布,线性外推直接崩。

## 这本身是个可写的结论

> 这些表征**对遮挡完全不鲁棒**:画面任意位置一个 20×20 的扰动,就足以让下游读出失效。
> 这和它们在**未被扰动**的受控渲染上 0.96–0.997 的可读性形成鲜明对比 ——
> 高可读性完全不蕴含对局部扰动的鲁棒性。

## 替代方案(不画图,给数)

不做逐像素图,改做**三块等面积区域的对照**:遮红球 / 遮干扰物 / 遮等面积空地,各自的 ‖Δz‖ 或读出偏差。
这样有对照、有量纲,而且能扩到 15 种干扰属性做成曲线。缺点是不如图直观。

## 成功的两张(2026-09-17 18:30)

前四种方法的共同病根:**都要么拟合探针、要么扰动图像,一做就跑出分布**。
换成"不拟合、不扰动、不求梯度"之后就成了。

### `direct_contrib.png` —— 直接用表征网络的权重算

`z = LayerNorm(proj(pooled))`,`pooled` 是 FPN 特征图的 7×7 网格平均,所以每个特征图像素对 z 的
贡献是**闭式的**:

```
贡献(y,x) = ‖ W[:, 该像素所属格子的 128 个通道列] @ p[:,y,x] / (格内像素数) ‖
```

一次前向 + 一次矩阵乘,精确值,p2(56×56)+ p3(28×28)+ p4(14×14)三尺度叠加。

**读图**:热区跟着**红色**走,不跟着**球**走 ——
蓝球/绿球/白球是冷区,红球、**红立方、红锥**都是热区;`init` 全图均匀,两球与背景无区别。

### `color_tuning.png` —— 颜色调谐曲线

探针在红球上拟合后**冻住**,只换目标球颜色(几何逐像素不变),看还能不能追踪到它。

# 起点:实现层面已精通,缺的是文献里的名字与因果方向;要求非学术化表达

用户已亲手实现并调试过 SAC / DDPG(DrQ-v2 风格)/ PPO / HER / SPR,读写这些算法的代码没有障碍,
并且能自主提出有水平的机制假设(2026-07-30 当天他自己提出了三个:「HER 一直传把 Q 拉高了吗」、
「是不是 SPR 导致状态漂移进而策略也飘」、「把死区直接设成 0.2」——第一个被数据否掉但方向对,
第二个因果方向反了,第三个经计算成立且优于我先前的方案)。所以**不要教 RL 基础**;
难度应该放在"机制的因果方向"和"什么算证据"上。

他明确要求:**不要学术腔,用词平常,多举例子**。已记入 `NOTES.md`。教学策略相应定为:
先用日常场景讲明白 → 再给英文术语(写论文需要)→ 例子优先用他自己项目的现象
(他见过 q1 从 6 涨到 45、机器人在停车区里每步满舵左右弹跳,这些是最好的记忆锚点)。

Mission 选的是"就是想真懂"(长期留存),不是为具体产出。因此课程要偏**检索练习**而非讲义,
并在后续课程里刻意做 spacing 与 interleaving,而不是一次讲透。

课 01 · 像素 RL 的表征问题

一个问题分清四条路线

大约 10 分钟。读 → 用自己的三条线练一遍 → 做 5 道检索题。

这节课你会拿到一个 30 秒判断法。以后看到任何一个"从图像学控制"的方法, 只问一个问题,就能说出它属于哪条路线、以及它的已知弱点是什么。

还会拿到一个反直觉的事实:文献里没有一篇"裸着用 RL 梯度训视觉网络"的成功案例。 每个成功都拄着拐杖。

先看一个日常场景

类比

你要教一个新来的实习生:看一眼监控画面,决定该往哪走。他有两件事要学—— 怎么看(从画面里提取有用的东西)和怎么决定(看懂了之后做什么)。 「怎么看」就是视觉 encoder,「怎么决定」就是策略和价值网络。

你有四种教法:

  • 只打分:你不教他看,只在他做完决定后告诉他"这次结果好不好"。他得自己反推 该注意画面里的什么。信号又弱又晚,而且他很容易为了迎合你的打分而胡乱总结规律 ——比如"上次画面右下角有个亮点,结果分高,那就盯亮点"。
  • 打分 + 额外练眼力:除了打分,还让他做"看这一帧,猜下一帧长什么样"的练习。
  • 打分,但把照片random裁剪一下再给他:每次给的画面都随机平移几个像素, 逼他别死记具体位置。
  • 先专门练眼力,练好后锁住:先让他看几万张图做"猜下一帧"的练习,眼力练成了, 从此不再改;然后只教他做决定。

这四种教法就是像素 RL 的四条路线。它们的区别只有一件事:"怎么看"这部分的参数, 到底被谁改。

那一个问题

encoder 的参数,出现在哪个 loss 的反向传播里?

整节课就这一句

路线encoder 被谁的梯度改平常说法代表工作
A只有 critic 的 TD 梯度,别的什么都没加裸着来 —— 见下文
BTD 梯度 加上 一个自监督 loss顺便练眼力 SAC+AE, CURL, SPR
C还是只有 TD 梯度,但输入先被随机增广把题目弄花 DrQ, DrQ-v2, RAD
DRL 梯度完全不进 encoder先练好再锁住 ATC, PVR, R3M, MVP, VIP

编号 A/B/C/D 是这门课自己的记法,不是文献里的标准叫法——写论文时要展开说 "encoder 由什么信号训练",别直接写"路线 C"。要用的英文术语在本页末尾。

拿你自己的三条线练一遍

你已经把四条路线里的三条亲手跑过了。这是这门课最好的锚点——因为你见过它们各自怎么活、怎么死。

你的线encoder 是什么 / 谁在改它路线结果
spr_z 预训练好的 SPR encoder,加载后 eval() + requires_grad_(False), 只训 actor/critic 头 D 稳定成功
sac_pixels 4 层 CNN 从头训;只有 critic 梯度进去;而且输入过了 RandomShiftsAug C 中期瞬态高峰,终态崩
sac_coadapt ResNet18+FPN 从头训;critic 梯度 和 SPR 自监督 loss 一起进去; 没有增广 B 成功率恒 0

两个容易漏掉的细节,值得单独记一下:

  • sac_pixels 其实不是"裸着来"。它在 update 里是 encode_pixels(..., augment=True),增广一直开着。也就是说它已经拄着 DrQ 那根拐杖了, 仍然崩——所以它的失败不能归因于"没加正则",得往别处找原因(这是下一课的内容)。
  • sac_coadapt 落在最脆弱的那一格。它是路线 B,而且连增广都没开 (cfg 里 AUG_PAD 旁边就写着"未用")。而恰好有一篇专门做系统评估的论文 ——Li et al., Does Self-supervised Learning Really Improve RL from Pixels?(NeurIPS 2022) ——结论是:同等数据与增广条件下,现有的"自监督 + RL 联合训练"框架相对纯增广基线 没有带来有意义的增益。

反直觉的那件事:路线 A 一篇都没有

把文献里所有"端到端从像素学会了"的成功案例摊开看,会发现一个规律: 每一个都至少带着一样额外的东西。没有一篇是裸的。

成功案例它拄的拐杖
DrQ (ICLR 2021) / RAD (NeurIPS 2020)输入随机增广
DrQ-v2 (ICLR 2022)增广 + 换成 DDPG/n-step + 探索噪声调度
SAC+AE (2019)自编码重建 loss 而且必须阻断 actor 梯度进 encoder
A-LIX (ICML 2022)对 encoder 梯度做自适应平滑正则
RLPD (ICML 2023)critic 里加 LayerNorm
BRO (NeurIPS 2024)强正则(论文明说:强正则是把 critic 放大的先决条件)

更值得琢磨的是 A-LIX 那篇顺手论证的一件事:图像增广之所以有效, 本质上起的就是梯度平滑正则的作用。也就是说路线 C 并不是"另一条路", 而是"路线 A + 一根隐形的正则拐杖"。

所以这张表真正的读法不是"端到端能行",而是: TD 梯度单独训不好视觉网络,得有人在旁边扶着。至于为什么扶不住就会倒—— 那是下一课。

去读这一篇

Cetin et al., Stabilizing Off-Policy Deep Reinforcement Learning from Pixels, ICML 2022 · arxiv.org/abs/2207.00986

为什么先读它:它同时给了两样东西——给"裸 TD 训 CNN 会怎么坏"起了名字 (visual deadly triad 和 catastrophic self-overfitting), 又论证了增广的本质是梯度正则,正好把路线 A 和 C 串起来。摘要 + 引言就够本节课用, 十分钟能读完。

如果只有五分钟:去看 ATC 的摘要一句话—— "training the encoder exclusively using ATC matches or outperforms end-to-end RL in most environments"。这是路线 D 最直接的一句背书。

随时问我。比如:为什么阻断 actor 梯度有用而阻断 critic 梯度不行?增广"等于正则" 到底怎么等的?我那条 pixels 线明明有增广为什么还是崩?——最后这个正好是下一课 (TD 梯度为什么会把表征学歪)的入口,想现在就聊也行。

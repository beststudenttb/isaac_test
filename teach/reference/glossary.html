四条路线(本课程的分法)

这个 A/B/C/D 的编号是本课程自己的分法,不是文献里的标准叫法,写论文时别直接用编号, 要展开说"encoder 由什么信号训练"。分法的依据只有一个问题:视觉网络的参数被谁的梯度改?

路线平常说法英文代表工作
A裸着用 TD 梯度训视觉 end-to-end TD, no regularization 没有成功案例(见 课 01)
BTD 梯度 + 自监督一起训 joint TD + auxiliary SSL loss SAC+AE, CURL, SPR
CTD 梯度 + 输入增广当正则 TD with data-augmentation regularization DrQ, DrQ-v2, RAD
D先单独练眼力,再锁住 decoupled / frozen pre-trained representation ATC, PVR, R3M, MVP, VIP

平常说法英文术语一句话出处
三件事凑一起会发散 deadly triad 函数近似 + 自举 + off-policy 同时在场时,价值估计没有收敛保证。注意原文的实证结论是 「发散不是必然」,它是总源头而非直接证据。 van Hasselt+ 2018, 1812.02648(preprint)
视觉版的那三件事 visual deadly triad TD 学习 + 卷积 encoder + 中等幅度奖励凑一起,CNN 会长出不平滑、过度判别的特征。 Cetin+ ICML 2022, 2207.00986
对自己编的答案死记硬背 catastrophic self-overfitting critic 的学习目标是自己算出来的,于是它对自己生成的目标过拟合,越练越离谱。 同上(A-LIX)
网络偷偷把表征学歪 feature co-adaptation
(implicit regularization)		 SGD 的隐式正则在监督学习里有益,在 TD 下变有害:把 Bellman 两端的 (s,a) 表征推向 共适应、点积变大、趋于塌缩。所以价值学习需要显式正则。 DR3, Kumar+ ICLR 2022, 2112.04716
特征越练越"扁" rank collapse /
implicit under-parameterization		 自举与梯度优化的病态互动使价值网络特征矩阵有效秩持续下降,梯度步越多表达力越差。 Kumar+ ICLR 2021, 2010.14498
学着学着就学不动了 capacity loss 在一串不停变的目标上训练,网络逐渐丧失拟合新目标的能力。稀疏奖励下最严重: 早期长期只能拟合近零目标,表征先塌了,等真信号来了已经学不动。 Lyle+ ICLR 2022, 2204.09560
网络失去可塑性 plasticity loss 上一条的后续机制分析:与 loss landscape 曲率变化深度相关,且常在没有饱和单元时就发生。 Lyle+ ICML 2023, 2303.01486
被开局的烂数据带偏 primacy bias 过拟合早期交互、忽视后期证据;周期性重置部分网络(保留 buffer)有一致增益。 Nikishin+ ICML 2022, 2205.07802
Q 值对没见过的动作乱报价 catastrophic overestimation critic 对数据外动作外推出离谱高值。LayerNorm 能让 Q 被权重范数界住,从而压住它。 RLPD §4.2, Ball+ ICML 2023, 2302.02948
换个种子结果差一个量级 seed variance;
报告规范:IQM		 少量 run 的 mean/median 点估计不可靠。要报区间估计、performance profiles、 interquartile mean (IQM)、stratified bootstrap 置信区间。 Agarwal+ NeurIPS 2021, 2108.13264

本项目自己的说法(文献里没有,内部沟通用)

本项目说法意思对应到文献
终止锚 replay batch 里 discount = 0 的那些样本(真正结束的那一步)。它们是唯一 不靠自举、直接把 Q 钉在真实回报上的样本。本项目实测这类样本只占 0.35%–0.87%。 没有标准术语。相关概念:bootstrapping、 absorbing state、time-limit handling(Pardo+ 2018 的 partial-episode bootstrapping)
冷启动死锁 成功需要一个罕见动作事件,而策略不产生它 → buffer 里没有成功样本 → critic 学不出来 → 策略更不会产生它。 最接近的是 capacity loss(稀疏奖励下表征先塌)与 exploration 文献; 本项目的具体形式是自己的
拐杖 路线 A 想成功必须带的东西:增广、encoder 梯度平滑、LayerNorm、周期 reset、 阻断 actor 梯度——至少一样。 本课程说法;逐项见上表

# HYPOTHESES

- **H1. 机制因果链**:目标在随机先验上难提取 → 必须重建新方向 → LayerNorm 定范数下零和 → 挤掉其余信息。
  支持:V4 的单调、S3、卷积块 ΔW 仅 2–19%。**没有干预实验**(没有去 LayerNorm / 换归一化的对照)。
- **H2. `a_w` 难提取是因为左右反对称**(奖励用 |bearing|,镜像不变)。Asym(把 a_w 换成 |a_w|)残留从 −0.079 升到 0.177,
  但该操作同时改变了对称性、分布和可提取性,**分不开**。
- **H3. V 与 sup 差,是因为没把分辨率放到停车区**(V11、S4)。相关性证据,未干预。
- **H4. "距离用画面高度"主要来自网格池化的架构先验**,而非训练选择:init 已表现出同样偏好(V9)。
  直接影响论文"表征选择了与 teacher 不同的线索"的措辞。需要换池化方式的对照才能确认。

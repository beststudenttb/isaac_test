# 2026-07-03 Ubuntu

## 近期推进

### 任务与 reward

- 将 stop 任务从固定点推进到可随机 stop 目标的设计：`end_d/end_x` 由 env 在 reset 时维护，reward、stop 区域、done 判断和 policy state 使用同一份目标。
- 将 teacher / student 的特权观测扩展为 `[px, dist, end_d, end_x]`，保证随机 stop 任务里策略能看到当前任务目标。
- 将 `FAIL_NEAR` 调整到更适合当前小机器人尺寸的范围，并把距离归一化统一到 `FAIL_FAR=8m`，避免旧尺度和当前任务边界不一致。
- 将 approach reward 的改善量改为固定尺度归一化：`px` 按图像宽度 `224`，`dist` 按距离范围，避免 px 与 dist 奖励量级过度不平衡。
- 多次分析 stop 区域内 reward 设计：`r_stop * stop_q` 太密集可能诱导停停动动或边缘行为；仅靠最终 success 又信号稀疏。当前倾向是保留清晰的 success 终止信号，谨慎加入 stop 内动作相关辅助。
- 将训练阶段的成功条件一度改为 stop 一次即 success，用于减少连续 stop 的稀疏性；评估阶段仍可用更严格的连续 stop 逻辑验证稳定性。
- 通过 rl_games preview 轨迹确认，云端模型在某些配置下不是公转，而是停在 stop 区外侧，表现为 action 已进入 deadzone 但 `dist` 尚未进 stop 范围。

### teacher / student / 视觉策略

- 随机 stop teacher 已能较好完成任务；固定 stop teacher 也保存过可用版本。teacher 的主要失败模式不是靠近阶段崩坏，而是不可见目标 search 阶段转头慢导致 timeout。
- 对 `old+shared`、MDP state 等视觉 student 做过多轮训练与离线评估。现象上，视觉 student 常出现前期成功率提高、后期变坏或震荡的问题。
- 分析认为，视觉 student 后期变坏不能只归因于 teacher 权重；stop 稀疏信号、动作 deadzone、PPO 随机采样、action clamp、视觉 state 表达都会共同影响。
- 对比有 teacher / 无 teacher 的视觉 student 后，teacher 能显著加速早期策略形成，但不保证后期稳定。teacher MSE 只拉 actor mean，不能直接控制 std。
- 记录并讨论了 teacher loss 与策略效果的矛盾现象：teacher loss 低不一定代表 deterministic 策略成功率高，因为 PPO 训练时采样动作、std、动作 deadzone 和 reward 都会影响闭环轨迹。

### MDP 表征路线

- 继续推进 MDP latent 方向：离线 MDP 预训练使用 forward dynamics、IDM、transition contrastive、probe 等组件。
- 明确 px/dist probe 目前主要作为诊断，不应默认作为主监督；如果让 px/dist loss 直接反传到 encoder，就会偏向人工几何表征，不再是纯自监督表征。
- 讨论并记录了 MDP 模型的关键风险：transition contrastive 可能包含同轨迹邻近帧假负样本；GRU/序列训练需要防止时序错位；probe 需要区分“诊断头”和“主监督”。
- MDP student 目前默认使用预训练 MDP checkpoint 接 PPO，在线 MDP 更新代码保留但当前主线不优先启用。
- 对 MDP student 失败轨迹的初步判断是：任务目标拼入 state 后不一定立刻变好，latent 与 goal 的融合方式仍可能太弱。

### SPR / PPO 路线

- 新增 SPR 方向：`src/cv_extractor/spr_state.py` 使用 ResNet18 + FPN + coord + conv，去掉显式 heatmap，提供 online/target encoder、transition、projector、predictor。
- 新增 `src/spr_ppo.py` 与 `train/spr_student.py`，用于 SPR latent + PPO + teacher MSE 的联合训练。
- 讨论了 SPR 的定位：SPR 原始思想中表征仍由 RL 主信号约束；在本项目中如果把表征与 PPO 分开，容易缺少明确主信号。
- 分析昨晚 `models/rl/spr_student`：`spr_loss` 全程为 0，说明 SPR 实际没有更新；这是旧激活逻辑导致的，不代表 SPR 本身无效。
- 进一步分析 std 发散：teacher MSE 只监督 actor mean，不更新 `log_std`；PPO 的 logprob 梯度会更新 `log_std`，尤其在 action clamp 和成功信号稀疏时，std 可能被推大。
- 将 `train/spr_student.py` 调整为保留 PPO 主信号、teacher MSE 辅助，并从训练一开始启用 SPR/encoder 更新：`SPR_START_ACTIVE=True`、`SPR_UPDATE_EVERY=1`。
- 新增短名诊断入口 `train/spr_bc.py` / `train/spr_bc_cfg.py`，用于 teacher MSE + SPR 的简单对照；但它没有 PPO 主信号，不是主线训练入口。

## 当前判断

- `old/shared` 视觉 student 后期变坏的问题，不应简单归因于 teacher 权重；纯视觉 state、stop 稀疏信号、动作 deadzone、PPO 采样分布和 action clamp 都会影响最终稳定性。
- 随机 stop 任务已经把目标 `end_d/end_x` 显式拼进 policy state；后续需要继续判断 goal 信息是否足够强，尤其是 MDP latent 维度较大时。
- teacher MSE 适合做动作均值模仿，但不能控制 std；std 发散要从 PPO 采样、action clamp、advantage 噪声和显式 std 约束几个角度处理。
- SPR 从一开始训练是必要对照；之前“SPR student”实际没有更新 SPR，因此不能用那次结果判断 SPR 表征是否有效。
- 只靠 `z,a -> z'` 的 SPR 转移不一定得到 PPO 最需要的表征；可能还需要 IDM、k-step、value/reward 辅助或更稳定的更新节奏，但每次只能改少量变量。
- 只用 teacher 会退化成示教/行为克隆，只适合做诊断；主线应保持 PPO reward 信号。
- 若要复杂化任务以体现自监督表征价值，优先考虑人工特征难以描述的任务，而不是继续只在简单 docking 上比较 px/dist 与 latent。

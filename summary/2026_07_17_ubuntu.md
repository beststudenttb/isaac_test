## 今日推进

### JSRL 初始化根因 + 修复（μ_y 漂移）

- 现象：σ=0.1 + 阶梯 JSRL 重跑失败，a_y（横移）动作 μ 被训练推到 +0.4，机器人抖着停不准。
- 逐层排查（都用静态方法，未启动仿真器）证伪了三个假设：不是"看不到球"（可见率 86%）、不是横移拿正奖励（a_y 与 x_gain/d_gain 均负相关，拿的是负分）、不是初始 μ 本身有问题。
- 真正根因：**actor 末层是裸 `nn.Linear`，用 PyTorch 默认 Kaiming 初始化（非零权重+bias），且末尾没有 tanh 居中**。实测真实 z 上初始 `μ_y ≈ +0.12`（weight 项 +0.074 + bias +0.047），不是 0。这是"PPO 策略头本应做小增益初始化让 μ≈0"这一标准步骤缺失——共享 `mlp`/`SPRActorCritic` 没做（CleanRL/SB3 用 orthogonal gain=0.01 专门干这个）。
- 概念澄清：`μ=0` 不是分布自带的常数（μ 是网络输出 `W·h+b`）；"均值 0"只对无穷多次初始化求平均成立，单个网络是一次具体抽样、必然非零；再叠加 z 非零均值 → μ_y 固定偏 +0.12。
- 修复（**局部、不碰共享框架**）：`train/spr_jsrl.py` 在 model 构造后、优化器前给 actor 末层 `weight.data.mul_(0.01); nn.init.zeros_(bias)`。实测初始 μ 三维全 ≈0（a_y +0.0006）。只作用于 JSRL 这一实例，`mlp` 定义/`SPRActorCritic` 类/teacher/别的线一字不动。
- 讨论过"加末尾 tanh"：证伪——`tanh(0.12)=0.12`（0 附近近似恒等），治不了初始偏移，还改共享类前向、破坏归档复现。选小增益初始化。
- 附带：为取 `ACTIVATIONS` 误 import 了 `spr_jsrl` 顶层 AppLauncher，无意拉起 Isaac 一次（自行 shutdown、无残留）。教训：验证策略网络该用裸 `nn.Tanh`，不导入 train 模块。

### 修复后诊断：σ 病没消失，搬家了

- 修复有效但只在 a_y：u690 per-dim σ = **a_x 0.100（顶 clamp）/ a_y 0.042（收）/ a_w 0.100（顶 clamp）**。a_y 治好，σ 病转移到 a_x（精确刹停）和 a_w（精确对准）两维。
- 训练成功率在 h=60↔135 大幅震荡（jsrl_success_ema 0.22~0.87），跑到 u690+ 不收敛；有意义交棒点峰值 ~0.76（略高于老 62.5%），但掉也掉到 0.3。
- 崩点轨迹（env0，崩点 vs 健康段对比）：**student 独扛接近段（student_frac 0.75→0.86）后刹不准、过冲**——把机器人开到 dist≈1.1m（穿过 1.5m 停车带没停住），再飘回 3m+。可见率 100%、不是找不到球。zone_frac 从 0.13-0.20 塌到 0.05。根子就是 a_x σ 顶死。
- 课程控制器病（用户 grill 出的两段因果）：**进档靠 teacher 灌水的 ema**——容易档 student_frac 只 0.4，ema 0.8+ 是 teacher 精确刹车刷的，控制器误判 student 会了、每 cooldown(11) 进一档，把没准备好的 student 火箭式送到 h=60；到墙后 student 独扛→骤降→跌破 down_thresh→在最难档爬不回→**回火级联**（h 60→135 每中间档只待 11 步、从不巩固）。中间难度从来只是过路，反向课程的"逐级掌握"被 bang-bang 废掉。

### 判决：停止微调 JSRL，重心转世界模型

- 证据链已收敛：h=60 给了 293 update 仍卡 0.66 爬不动（≈固定难档给足时间的实验）+ σ 精度维顶死 + 过冲崩点 + 同一 z off-policy 100%。**这是"课程+初始化能治乱侧移/走到区，治不了精确刹停对准（稀疏终止信用传不到精度维）"的干净反面证据。** 再调控制器天花板不动。
- 决定：**不再微调**，等这次跑 + val 收尾即归档为负结果；重心转世界模型（Dreamer/TD-MPC on 冻结/共学习 SPR latent），符合既定"off-policy/model-based 主场"策略。
- on-policy 回归的**真扳机**（只有这些值得回）：不靠 replay 把稀疏终止奖励的信用送到精度维——奖励重分配/return decomposition、per-dim σ 控制、或刹车段 dense 辅助信号。小修小补不回。
- 可选廉价收尾（未做，留待需要时）：固定 h=90/105 + 禁 ladder 探针，把"控制器太快 vs σ 病墙"分离干净，让负结果投稿无懈可击。

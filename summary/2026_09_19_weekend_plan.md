## 1. 为什么做这个

现在的 2 物体环境有一个**无法分开的混淆**:干扰球(蓝球)**既是干扰物、又是非红物体**。
所以"A 丢弃干扰物"和"A 丢弃非红物体"这两个完全不同的结论,**在现有数据上不可区分**。

已有证据强烈指向后者:A 的响应跟着**红色像素面积**走(红大球 0.765 > 红立方 0.731 > 红球 0.607
> 红锥 0.519),对蓝球只有 0.017;而颜色扫描显示抑制排序与自身颜色调谐曲线同序。

**4 物体的 2×2 设计能拆开它**,因为**红方是一个能通过颜色滤波器的干扰物**。

## 2. 设计

**环境**:4 个物体,每回合都出现、位置各自独立采样(保持最小间距)

| 物体 | 与目标共享 |
|---|---|
| **红球(目标)** | — |
| **红方** | **颜色** |
| **蓝球** | **形状** |
| **蓝方** | 都不共享 |

这正是视觉注意里的 **conjunction search / 特征绑定**设计(Treisman)。

**teacher**:1 个,追红球,`obs=diam`(相机坐标)+ `score_mode=angle`(物理奖励)。

> `models/rl/teacher_score_g4_diam_angle_s2`**。理由:
> ① teacher 无相机、吃特权观测、训练环境是干净场景,**4 物体与 2 物体对 teacher 完全等价**,
>   重训只是重新掷一次骰子,不会更"对";
> ② 该 teacher 已验过 **v1=100%、回报 276.2**(同组 s1 是 100% / 273.9,当时取的就是 s2),
>   "2–3 seed 取最优防坏 teacher"的目的已经达成,而且是**已经兑现的**,不是待赌的;
> ③ **现有全部结论都建在这个 teacher 上** —— 复用它,4 物体的结果与 2 物体的结果才直接可比,
>   否则横向排序的比较会混进"换了 teacher"这一项;
> ④ 省下 2–3 小时,并去掉一整个失败阶段。

**表征**:5 个 —— A / V / R / sup 用红球 teacher 的信号训,init 随机不训

**PPO**:**4 个任务** = 四个物体分别当目标;只换奖励与停车判定的对象,场景完全一样

**规模**:1 teacher + 5 表征 + **24 条策略**;A / R / sup / init 单 seed,**V 跑 2 seed**
(V 在红球任务上三 seed 是 68.8 / 100.0 / 68.8,**极差 31.2 点**,单 seed 读不出东西;
A 极差 7.8、R 极差 1.5,单 seed 可读)

**方块尺寸**(用户 2026-09-18 定):**边长 = 球直径 = 2r**,即外接盒与球相同,沿用现有实现。
代价是方块的**正投影面积比球大 4/π ≈ 1.27 倍**,而 A 的响应是跟红像素面积走的
(红大球 0.765 > 红立方 0.731 > 红球 0.607 > 红锥 0.519)。
**因此分析时必须把各物体的像素面积作为协变量一并报出**,否则「追红方」跑得好说不清是颜色还是面积。

## 3. 事先写死的预测

| 若某信号… | 4 物体环境里的表现 |
|---|---|
| **只做颜色过滤** | 红球、红方都编码;蓝球、蓝方都不编码 |
| 只做形状过滤 | 红球、蓝球都编码;两个方都不编码 |
| **真的区分目标** | 只编码红球,其余三个都不编码 |
| 不过滤 | 四个都编码 |

**具体预测**:

1. **A / sup 走"颜色过滤"那一格** —— 红方的位置会像目标一样被编码,
   因此**「追红方」的 PPO 成绩会异常地好**,而「追蓝球 / 追蓝方」死掉(≈10–20%)。
2. **R / init 基本不过滤**,四个任务的成绩接近。
3. **V 介于中间,偏 R 一侧。**
4. 表征侧:A 对红方的 ‖Δz‖ 位移应与对红球相当(按面积甚至更高),对蓝球/蓝方应 ≈0.02。

**判决**:
> **若用 A 的表征「追红方」能跑到 80%+,则"A 只学了颜色滤波器、没学目标"得到行为级证据。**
> 那么此前"A 丢弃干扰物"的说法必须改写成 **"A 丢弃非红物体"**,
> 而"目标 vs 干扰"的区分**没有任何一个信号学到**。

这一条比"换任务会崩"深一层:它区分的是**过滤**与**区分**。

### 3.1 「结论一致 / 不一致」的判定(用户 2026-09-18 定)

**不看成功率的绝对数值,也不要求可解释性达到单干扰任务的水平。**
只看**多干扰环境内部、各臂之间的横向对比**是否与现有结论同序。要复现的横向结论是:

| 要复现的 | 现有依据 |
|---|---|
| A 在原任务与 R 齐平,换目标后塌 | 红 95.8 / 蓝 10.4 |
| R 换目标仍保持,且 **R ≥ A** | 红 97.9 / 蓝 83.3 |
| init 大致对称(各目标任务接近) | 76.6 / 81.2 |
| sup 最差 | 16.7 / 25.0 |
| V 不稳、居中偏 R 一侧 | 79.2 / 78.6,极差 31.2 |

**横向排序复现 → 算一致,不补种子。某一臂打破排序 → 只给那一臂补 1 个 seed。**

### 3.2 加测:颜色权重 vs 形状权重(用户 2026-09-18 同意)

光有 24 条 PPO 成绩,拿不到"**各臂分别选了哪条线索**"这个数。补一批**受控渲染**
(几十分钟,CPU/单卡零占用冲突):固定几何、逐个物体换属性,对每个表征回归出
**色相权重**与**形状权重**,同时记录**每个物体的像素面积**当协变量。

- 若各臂的颜色/形状权重**不同** → 选择性的第二个实例(不同信号选了不同线索),进论文第二档
- 若各臂权重**一样** → 说明这一维也是被环境解出来的,自发栏仍只有「身份=红」「距离=图像高度」两条

两种结果都写。

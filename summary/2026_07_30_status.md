## 1. 结论:Q 为什么飞(逐条有实测支撑)

**顺序:Q 飞 → 策略满舵 → 撞出界变多 → 分布劣化 → SPR 学坏 → 表征漂移。** 不是反过来。

- **时序证据**:coadapt 在 13 万步时 q1 已 6→35、a_mag 已 0.96,而 z_std 还趴在 0.166;
  z_std 要 30 万步后才起爬(末值 ~2.4)。**先 Q 后表征**,差 2 倍时间。
- **排除 SPR**:`sac_pixels_8m` 完全没有 SPR(纯 4 层 CNN、只有 critic 梯度),q1 同样 9.7→47、
  a_mag 同样 0.95。SPR 不是必要条件。coadapt 的 `spr_loss` 全程稳在 0.12–0.23(自监督本身健康)。
- **排除"z_std 抬高 Q"**:`Critic.trunk` 第一层是 `Linear→LayerNorm→Tanh`,z 的整体尺度进 Q 前
  被归一化掉。z_std 膨胀是同一个坏梯度环的另一个症状,不是 Q 的原因。
- **排除"HER 灌正奖励"**(用两条 run 自己的 `traj_train_env0.csv` 重跑 relabel 数学):
  relabel 后 reward 均值 **负**(coadapt −0.167 / pixels −0.218),进区(+1)与出区(−2)几乎等频。
  HER 没有净正奖励。
- **HER 的真实份额**:① 把"刚进区"这个可被高估的事件密度**翻倍**(真 goal 7.8–9.7% →
  relabel 后 16.5–20.3%);② relabel 样本 `P(terminated)=0.0000`,**一个锚都不贡献**。
- **锚的稀缺是量化的**:episode ~375 步、每条 1 个终止步 → 带 `discount=0` 的样本占比
  coadapt 0.35% / pixels 0.39% / spr_z 0.87%,99.6% 是纯自举。`R_STOP_IN=+1` 是**非终止**奖励
  → Q 天花板 `1/(1−γ)=100`,而真实可达回报只有约 11。**q1=45 是错觉,不是钱。**
- **分水岭是表征可训性,不是熵**:spr_z 的 alpha 更低(0.002–0.004)、entropy 同样钉在 −3.0,
  但 q1 全程 ≤6.2、critic_loss 0.22。coadapt/pixels 的 critic_loss 是 3.2–6.5(15–29×)。
  → 冻结表征能把 +1 和随后必至的 −2 绑在同一 (状态,goal) 上互相抵消;表征在动就绑不住。
  **更正 `2026_07_29_sac_her.md` 里"alpha 塌太快"的说法——数据不支持。**

## 3. 任务 v2(hover)= 悬停 + 部署切断

计划见 `2026_07_30_hover_v2_plan.md`。核心:训练只给**状态分**、episode 强制跑满,停止移出 RL。

- **训练奖励**:保留 goal 无关项(搜索 / K_TIME / R_FIND / R_LOST / telescoping 接近 shaping),
  新增主项 `seen → +R_HOVER·stop_q`(现有二维高斯原样复用);**删掉全部事件配对与终止项**
  (`R_STOP_IN/OUT`、`K_STOP_DA`、`R_STOP`、`R_SUCCESS`、`R_FAIL`);`compute_terminated` 恒 False。

  无提前终止→大量"区内"样本,且奖励自洽后 TD 有稳定不动点(pendulum 范式)。
- **代码**(全部离线验证过,未提交):

  - `src/hover_env.py` 新增 `HoverMixin` + Hover{,Noise}StudentEnv:**先跑完整 v1 链再逐项精确撤项**
    (super 负责全部薄记;v1 的 prev_* 是重绑不是原地改,进 super 前留旧引用即可)——v1 改了 v2 自动跟;
  - `train/spr_student.py --hover`(输出目录加 `_hover`,硬检查 VAL_EVERY==0);
  - `val/spr_student.py --hover`:**env 仍是 v1**(判据与 88%/92% 可比),只在动作侧套切断 wrapper
    (连续在区 `HOVER_CUT_N=3` 步 → 动作强制 0,done 时清零);
  - `scripts/run_spr_hover_pipeline.sh`。
- **验证**:撤项代数逐元素相等(40 步×64env,故意把 `K_STOP_DA=0.7/R_STOP=0.4` 设非零证明真撤掉)、
  覆盖进/出区/success/fail/低动作全分支、`compute_terminated` 恒 False、无事件级跳变;
  切断 wrapper 的 streak 语义四情形单测通过。

## 4. hover 奖励设计的定量体检(今天最重要的开放结论)

**有 stop 信号,但是位置级的,不是动作级的。**

- 位置级信号很强:完美悬停 375 分 vs 实测那个满舵极限环 188 分,**差一倍**。所以"学不会别动"不成立。
- 尺度合适:一步满舵 **转头 8.4px(1.68·SIG_X)**、横移 3.6px(0.71σ)、纵向 0.4·SIG_D。
  注意 **px_x 的主导驱动是转头(a_w),是横移的 2.4 倍**——这解释了 pixels 那个 11.8px 宽的极限环。
- **但动作级的 stop 拿不到**:`stop_q ≈ 1 − 0.35|a|²` 是二次的,越小越平。
  0.3→0.2 只赚 6.4 分(1.7%)、0.2→0.1 赚 3.9(1.0%)、0.1→0.05 赚 1.0(**0.3%**)。
  在 advantage 归一化 + value 误差之下这是噪声底以下。平区里 on-policy 就是随机游走,
  **终态会平衡在 |a| ~ 0.2–0.3 游荡,永远不进 0.05**。
  (推论:σ 退到 0.02 使死区"可达"(落入率 96%)但**不使它有吸引力**——落入率≠梯度,此前判断已更正。)
- **抬死区是对症解**(用户提议):死区内运动恒 0 → `stop_q` 恒 1,边界出现**断崖**;
  被 σ 平滑后边界梯度 = 断崖/σ,`eps=0.2` 时为 262,是同处光滑梯度(52)的 **5 倍**。
  几何上关键:eps=0.05 时平衡幅度 0.2–0.3 落在死区**外**;eps=0.2 时落在**内**,
  而**进去之后随机游走无害**(立方体内每点都零运动、都满足判据)。断崖只需守边界,而它正在那里。
  另:`|a|<eps` 时 `move_actions` 清零 → `[-eps,eps]³` 整个立方体等价"完全不动",最优动作是有体积的集合。
- **守恒律**:断崖高度 ≡ 精度代价(同一个数)。eps=0.2 买到 5× 梯度,代价是可达上限 375→370(1.4%)。
  分维度设阈值也逃不掉(两边同系数缩放)。
- 副作用两条:① 区内 approach shaping 被 `~stop` 门关掉,而区边界 `stop_q` 只有 0.018(2σ×2σ)
  → 刚进区有弱信号带(备选修法:去掉 `~stop` 门让 telescoping 一直管到中心,势函数差,HER 安全);
  ② 出界不再终止也不再罚 → 会长时间待在 dist<0.5m 或 >8m 的**分布外**状态(env 是运动学写位姿,
  不碰撞,不是 bug,但 encoder 从没见过)。

## 今日推进

### 新开 off-policy 线（DrQ-v2）

- 动机：三条视觉 PPO 线（old_shared / MDP / SPR）的失败已定位到 σ。success 要求三维动作同时 `|a_i|<STOP_EPS=0.05`，成功概率 `≈[2Φ(0.05/σ)-1]³`；而 PPO 的 `log_std` 是可学参数，在这个稀疏 reward 下梯度拿不到信号，SPR 线 σ 被钉死在 0.299/0.100（顶 clamp）。DrQ-v2 的 DDPG actor 走 `∇_a Q`，σ 是**调度**出来的（不是被学的），且有 replay 复用稀有成功、eval 是确定性 μ——正中三个要害。**刻意不用 SAC**（熵目标会把 σ 顶在目标熵上，复现要逃离的病）。
- 新文件：`src/drqv2_agent.py`、`src/drqv2_buffer.py`（Codex 写的 n-step 向量化 replay + FrameStack）、`train/drqv2.py`+cfg、`val/drqv2.py`+cfg、`scripts/run_drqv2_pipeline.sh`。用影子日志 oracle 核过 n-step return / terminated-vs-truncated bootstrap / 跨 episode 不泄漏，全绿。
- 两条 arm：**arm A** = 冻结现成 SPR z + DrQ-v2 学习器（单变量对照「同一个 z、换算法」）；**arm B** = DrQ-v2 原版像素（可训练 CNN + RandomShiftsAug）。

### arm A：判决实验（同一个 z，off-policy 100%）

- 冻结 encoder = `models/rl/_encoders/stage1_sigma_ablation.pt`（权重 hash `84fd8456`），和 σ 调度消融那次 PPO 用的**逐字节相同**的 z。
- 结果：离线 deterministic **success 100%，de 0.022m、xe 0.9px**。训练里 σ≈0.18 起飞，一路到 σ=0.05 收 95%+。
- 对照钉死：**同一个 z**，PPO（σ 调度/无 BC）峰值 28% 后塌到 0；PPO+BC(teacher=5) teacher 撤光后 0%；DrQ-v2 **100%**。**唯一变量是算法。** 这是三条无特权线里唯一跑通的——论文核心结果。

### σ 病机制 + critic 友好度实验

- 量出根因：stop 区 shaping 是关闭的（`R_STOP=0.0`），且 `d_gain`（0.0018/步）< `K_TIME`（0.003/步）——**shaping 在惩罚"靠近"**。唯一能压过的是终止 `R_SUCCESS=10`，而只有 replay 能把它沿接近轨迹反传；PPO 的 GAE 配一个 `v_loss≈0.003` 的死 critic 传不动。
- 无-Isaac 实验（`scratchpad/critic_friendly.py` + `td_fixed.py`）：同一批 teacher 数据，同一个 [64,64] MLP。**监督拟合折扣回报 R²：SPR z 0.84 > MDP z_img 0.78、mdp_state_feat 0.78、真值 oracle 0.78。** 即 SPR z 对 critic**不但够、还是最友好的**。而 TD(0) 全军覆没（连 oracle 也 −0.08）；n=17（GAE 有效视野）才逼近监督上界。结论：**表征没问题，失败纯粹是稀疏终止奖励的信用分配——on-policy 只能撞一次用一次、传 17 步；off-policy 的 replay 反复回放整条轨迹。**

### JSRL + 反向课程 SPR-PPO（反面结果，已归档）

- 思路：teacher 带路把机器人开到"快停车"，student 从那里接手、只学最后一段（反向课程），学会了再把接棒点往前挪。approach B：只收集 student 步（不 mask），base `spr_ppo_update` 不用改。清理了 `spr_student.py` 的旧改动，JSRL 全部搬进新文件（`src/spr_jsrl.py`+train/val/sh，继承 `SPRRollout`）。
- 结果：反向课程完整展开（h 150→0），success 从 0 爬到 ~62.5%（离线 best，h=20），然后卡死；h→0 反而退化到 41%。根因：`a_w`（转头维）的 σ 顶死 0.3 clamp 整整 880 个 update——**课程解决了"走到区"，解决不了"精确对准"**。同一个 z：off-policy 100% vs on-policy+课程 62.5%。归档 `approved_models/2026_07_16_spr_jsrl/`。

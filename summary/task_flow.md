# Task Flow

本文档只记录找球任务的流程语义，不记录 reward 细节和参数配置。

## 基本设定

- 默认每个 episode 开始时机器人看不到目标。
- 目标是先通过头部旋转或机器人运动找到小球，再接近小球，进入 stop 区域后完成停止。

## 关键时刻

1. reset 时刻：episode reset 后的第一步；通常看不到目标。
2. 小球进入视野时刻：目标第一次进入相机视野。
3. 进入 stop 区域时刻：目标进入预设停止区域。
4. done 时刻：机器人满足成功或失败条件，episode 结束。

## Stage

1. 找球 stage：从 reset 时刻开始，到小球进入视野时刻结束。
2. 接近 stage：从小球进入视野时刻开始，到进入 stop 区域时刻结束。
3. 停下之前的 stage：从进入 stop 区域时刻开始，到 done 时刻结束。

## 完整流程

1. reset 后进入找球 stage。
2. 找球 stage 中目标不可见，机器人通过转头搜索目标。
3. 小球第一次进入视野后，进入接近 stage。
4. 接近 stage 中机器人靠近小球，并让小球保持在视野中心附近。
5. 目标进入 stop 区域后，进入停下之前的 stage。
6. 机器人在 stop 区域内输出 stop 动作并保持稳定后，success done。
7. 如果 episode 超时或触发边界失败条件，则 fail done。
